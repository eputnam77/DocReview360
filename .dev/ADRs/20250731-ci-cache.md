# 20250731 - Finalize CI Caching Strategy

## Status
Accepted

## Context
Previous ADRs introduced a basic GitHub Actions workflow and pinned dependencies
using Poetry. The workflow should reuse the virtual environment across runs so
that CI remains fast even as the project grows.

## Decision
- Keep `poetry.lock` under version control and use it as the cache key.
- Cache both the Poetry download directory (`~/.cache/pypoetry`) and the `.venv`
  folder in `ci.yml`.
- Reinstall dependencies with `poetry install --with dev` so tooling and tests
  share the same locked versions.

## Consequences
- Dependency upgrades invalidate the cache automatically.
- CI setup time is reduced because the environment only rebuilds when the
  lockfile changes.
