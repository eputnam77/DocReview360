# 0005 - Documentation Strategy

DocuFlow keeps two kinds of documentation:

* **User guides** and API references live in the `docs/` folder and are published with **MkDocs Material**.
* **Development records** such as detailed ADRs and planning notes stay in `.dev/` and are not distributed.

Important decisions are summarised in this folder so readers of the public site understand the rationale without navigating the entire development history.
